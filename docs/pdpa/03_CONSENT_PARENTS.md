# หนังสือแจ้งการประมวลผลข้อมูลส่วนบุคคล และขอความยินยอม
### สำหรับผู้ปกครอง — ออกโดยโรงเรียน

> ⚖️ **ร่าง — ต้องให้ทนายตรวจก่อนนำไปใช้** · ผู้ร่างไม่ใช่ผู้ประกอบวิชาชีพกฎหมาย
>
> 🔴 **เอกสารนี้แยกเป็น 2 ส่วนโดยตั้งใจ** และต้องไม่รวมกัน:
> **ส่วนที่ 1 คือการ "แจ้ง"** (ม.23) — ผู้ปกครองไม่ต้องเซ็นก็มีผล
> **ส่วนที่ 2 คือการ "ขอความยินยอมโดยชัดแจ้ง"** (ม.26) — **ต้องเซ็น และต้องปฏิเสธได้**
>
> กฎหมายห้ามทำให้ความยินยอมเป็นเงื่อนไขของการรับบริการ
> ถ้าผู้ปกครองไม่ยินยอมข้อใด **ลูกต้องยังเรียนได้** — ส่วนนั้นจะไม่ถูกบันทึกเท่านั้น

# ส่วนที่ 1 · การแจ้ง (ไม่ต้องลงนาม)

## 1.1 ใครเก็บข้อมูลของบุตรท่าน

| | |
|---|---|
| **ผู้ควบคุมข้อมูลส่วนบุคคล** | `[ชื่อโรงเรียนเต็ม]` — เป็นผู้ตัดสินใจว่าจะเก็บอะไร เพื่ออะไร และเป็นเจ้าของข้อมูล |
| **ผู้ประมวลผลข้อมูลส่วนบุคคล** | `[ชื่อผู้ให้บริการระบบ]` — ดูแลระบบให้โรงเรียน **ทำได้เฉพาะตามคำสั่งโรงเรียน และไม่ใช่เจ้าของข้อมูล** |
| **ติดต่อเรื่องข้อมูลส่วนบุคคล** | `[ชื่อ · ตำแหน่ง · อีเมล · โทร]` |

## 1.2 เก็บอะไร เพื่ออะไร

| เก็บอะไร | เพื่ออะไร | ฐานทางกฎหมาย |
|---|---|---|
| ชื่อ · ชื่อเล่น · วันเกิด · เพศ · รูปถ่าย · เลขบัตรประชาชน | ระบุตัวเด็ก · ออกเอกสารทางการศึกษา | สัญญา / หน้าที่ตามกฎหมาย |
| ชื่อ · เบอร์โทร · ที่อยู่ · บัญชี LINE ของผู้ปกครอง | ติดต่อ · รับ-ส่งเด็ก · แจ้งเตือน | สัญญา |
| ผู้มีสิทธิรับเด็ก (ชื่อ · เบอร์โทร · ความสัมพันธ์) | **ความปลอดภัยในการส่งเด็กกลับบ้าน** | ประโยชน์สำคัญต่อชีวิต |
| เวลารับ-ส่ง · การลา · การขาด | ดูแลเด็ก · คิดค่าบริการ | สัญญา |
| ค่าเทอม · การชำระเงิน · สลิปโอนเงิน | เรียกเก็บและออกใบเสร็จ | สัญญา / หน้าที่ตามกฎหมาย (ภาษี) |
| บันทึกประจำวัน · รูปภาพกิจกรรม | รายงานผู้ปกครอง | สัญญา *(รูปภาพ — ดูส่วนที่ 2 ข้อ 2.3)* |

## 1.3 เก็บไว้นานแค่ไหน

| | |
|---|---|
| ข้อมูลเด็กและผู้ปกครอง | `[__]` ปี นับแต่วันที่เด็กออกจากโรงเรียน *(เสนอ: 5 ปี)* |
| เอกสารทางการเงิน | ตามที่กฎหมายภาษีกำหนด |
| เมื่อครบกำหนด | **ลบอย่างถาวร** |

## 1.4 ข้อมูลถูกเก็บที่ไหน และใครเห็นได้

- ระบบเก็บข้อมูลไว้บนเซิร์ฟเวอร์ที่ **ประเทศสิงคโปร์** และใช้บริการของ **Google** และ **LINE**
  ซึ่งเป็นผู้ให้บริการต่างประเทศ — ถือเป็นการส่งข้อมูลไปต่างประเทศตามมาตรา 28
- **ท่านเห็นได้เฉพาะข้อมูลบุตรของท่านเท่านั้น** ผู้ปกครองรายอื่นไม่เห็นข้อมูลบุตรของท่าน
- คุณครูเห็นเฉพาะเด็กในชั้นที่ตนรับผิดชอบ
- **โรงเรียนไม่ขายและไม่เปิดเผยข้อมูลแก่บุคคลที่สามเพื่อการโฆษณา**

## 1.5 สิทธิของท่าน (หมวด 3)

ท่านมีสิทธิ **ขอดู · ขอสำเนา · ขอแก้ไข · ขอลบ · ขอให้ระงับการใช้ · ขอคัดค้าน · ขอถอนความยินยอม**
และ **ร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล**

ติดต่อตามข้อ 1.1 · โรงเรียนจะตอบภายใน **30 วัน**

# ส่วนที่ 2 · ขอความยินยอมโดยชัดแจ้ง (ต้องลงนาม)

> 🔴 **ข้อมูลด้านล่างนี้เป็น "ข้อมูลอ่อนไหว" ตามมาตรา 26** ซึ่งกฎหมายกำหนดให้ต้องขอความยินยอม
> **โดยชัดแจ้งและแยกต่างหาก** จะอาศัยการแจ้งในส่วนที่ 1 อย่างเดียวไม่ได้
>
> **ท่านปฏิเสธข้อใดก็ได้ และบุตรของท่านยังเรียนได้ตามปกติ**

ข้าพเจ้า `[ชื่อ-นามสกุลผู้ปกครอง]` ผู้ปกครองของเด็ก `[ชื่อ-นามสกุลเด็ก]`

### ☐ 2.1 ข้อมูลสุขภาพ — **เพื่อความปลอดภัยของบุตรท่านโดยตรง**

ยินยอมให้โรงเรียนเก็บและใช้ **อาการแพ้ · ประวัติการรักษา/โรคประจำตัว · หมู่เลือด · ประวัติวัคซีน**
เพื่อดูแลบุตรของข้าพเจ้า และเพื่อให้ความช่วยเหลือได้ทันทีเมื่อเกิดเหตุฉุกเฉิน

> ⚠️ **ถ้าไม่ยินยอมข้อนี้** โรงเรียนจะไม่มีบันทึกเรื่องอาการแพ้ของบุตรท่าน
> และ**จะไม่สามารถแจ้งโรงพยาบาลได้ทันทีเมื่อเกิดเหตุ** — โปรดพิจารณาด้วยความระมัดระวัง

## 📋 บันทึกถึง ผอ. — 3 เรื่องที่ต้องตัดสิน

1. **ข้อ 2.4 (ศาสนา/เชื้อชาติ)** — โรงเรียนใช้ข้อมูลนี้จริงหรือไม่?
   ถ้าไม่ **ผมถอดออกจากระบบให้** จะลดภาระเอกสารและความเสี่ยงลงทันที
