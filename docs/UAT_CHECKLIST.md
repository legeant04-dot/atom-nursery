# 🧪 เช็คลิสต์ UAT — ทดสอบระบบใหม่ก่อนขึ้นจริง

*ร่าง 2026-11-14 · ใช้กับ `docs/ROLLOUT_PLAN.md` · วันที่จริงรอ ผอ. ยืนยัน อา. 15/11 (ร่างเร็ว: 20–25 พ.ย. · ร่างเดิม: 30 พ.ย.–4 ธ.ค.)*

**เป้าหมาย:** ผอ. + แอดมิน + ครูนำร่อง ใช้ระบบใหม่ **บนมือถือของตัวเอง** กับ **สำเนาข้อมูลจริง** ทำงานแบบวันปกติ
แล้วบอกได้ว่า "ใช้แทนของเดิมได้" — ไม่ใช่แค่ "เปิดได้"

> 🔴 **UAT ไม่แตะผู้ใช้จริง:** ข้อมูลเป็นสำเนา (ล้างแล้วย้ายใหม่ทั้งหมดในคืนย้าย) · LINE ส่งเฉพาะผู้ทดสอบ · Apps Script เป็นโปรเจ็กต์แยก
> สิ่งที่กดใน UAT (บิล · รับเงิน · เงินเดือน) **ไม่ติดไปถึงของจริง** — กดได้เต็มที่
