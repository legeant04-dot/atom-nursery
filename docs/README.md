## ข้อสรุปหลัก ถ้าอ่านได้แค่ย่อหน้าเดียว

> **ปัญหาทั้งหมดของระบบวันนี้มาจากที่เดียว คือฐานข้อมูล** — Apps Script รันได้ทีละคำสั่งต่อผู้ใช้ และ
> Google Sheets ไม่ใช่ฐานข้อมูล นั่นคือที่มาของ p50 6.8 วินาที และเป็นที่มาของ cache, micro-batching,
> round-trip budget ทั้งหมดที่เราสร้างขึ้นมาแก้ขัด
>
> ดังนั้น **ย้ายไป Postgres คุ้มค่าในตัวเอง** ส่วนการเขียนหน้าจอใหม่เป็นการตัดสินใจเชิงสินค้า ไม่ใช่เรื่องความเร็ว
> — สองเรื่องนี้ไม่ควรเป็นโปรเจกต์เดียวกัน และฐานข้อมูลต้องไปก่อน

## สิ่งที่ตัดสินใจไปแล้ว

| | |
|---|---|
| Database | **Supabase (PostgreSQL)** · region สิงคโปร์ |
| Hosting | **Vercel** · function pin ที่สิงคโปร์ · ทางออกคือ Cloudflare |
| Auth | **ไม่ซื้อ vendor** — ใช้ session ของเราเอง (v383) แล้ว mint JWT ให้ Postgres เชื่อ |
| รูปภาพ | **Cloudflare R2** (egress ฟรี) |
| อัตโนมัติ | **n8n** (จัดตาราง + แจ้งเตือน ไม่แตะการคำนวณเงิน) |
| ทางเข้า | **LINE LIFF เหมือนเดิม** — ไม่เปลี่ยนประตูของผู้ปกครอง |
| ชำระเงิน | **SlipOK เหมือนเดิม** — ไม่แตะ |
| ราคา | **฿199 / ฿299 / ฿399 ต่อเด็กต่อเดือน** · ขั้นต่ำ 20 คน · เกิน 30 คนเป็นใบเสนอราคา |
| Multi-tenant | **ต้องเสร็จก่อนขาย** → `tenant_id` ลงทุกตารางตั้งแต่ migration แรก |
| App Store | **เลื่อนไปก่อน** · Play Store ทำได้ |
