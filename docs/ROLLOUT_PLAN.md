## 🔴 ข้อที่ห้ามพลาด: ข้อมูลต้องอยู่ที่เดียว

```
วันนี้      ผู้ใช้ ──→ Apps Script ──→ Google Sheets        (โฮสต์ใหม่ทำงานกับข้อมูลทดสอบเท่านั้น)

หลังขั้น A  ผู้ใช้ ──→ Apps Script ──→ Postgres              (ช้าเท่าเดิม แต่ข้อมูลย้ายแล้ว)

หลังขั้น B  ผู้ใช้ ─┬→ โฮสต์ใหม่ ────→ Postgres  ← ตัวเดียวกัน
                 └→ Apps Script ──→ Postgres  ← อัปโหลดรูป · SlipOK · ล็อกอิน · ตั้งเวลา
```

**ทำไมเปิด "ทีละกลุ่มผู้ใช้" ก่อนย้ายข้อมูลไม่ได้:** ถ้าครู ก. ใช้โฮสต์ใหม่ (เขียน Postgres) แต่ครู ข. ยังใช้ Apps Script (เขียนชีต)
จะมีข้อมูลสองชุดที่ไม่ตรงกัน — ครู ก. เช็คอินเด็กแล้ว ครู ข. ไม่เห็น · บิลที่ออกฝั่งหนึ่งไม่มีอีกฝั่ง
ตัวซิงก์ `pg_sync` เป็นทางเดียว (ชีต → Postgres) ตามรอบ โดยตั้งใจ จึงแก้ปัญหานี้ไม่ได้

→ **ข้อมูลย้ายทั้งโรงเรียนครั้งเดียว · คำขอค่อย ๆ ย้ายทีละกลุ่ม** — นี่คือโครงของทั้งแผน

| B1 | **เครื่องนำร่อง** — ผอ. · ครู 1–2 ท่าน · ผู้ปกครองอาสา 2–3 ครอบครัว | การอ่านทั้งหมด | ไม่มี error ใหม่ · ตัวเลขบนจอตรงกับเครื่องที่ใช้เส้นเดิม |
| B2 | เครื่องนำร่องเดิม | + เขียนทั่วไป (W1–W2: ประกาศ · สมุด · ความเห็น · ลาเด็ก · แจ้งบาดเจ็บ) | LINE ถึงคนที่ควรได้ ไม่ซ้ำ ไม่ขาด |

> **เงินเปิดท้ายสุด และไม่ตรงกับรอบออกบิล/จ่ายเงินเดือน** — เปิดกลุ่มเงินเดือนหลังจ่ายเดือนนั้นแล้ว ไม่ใช่ก่อนวันจ่าย

**อยู่ Apps Script ตลอดไป (ไม่ย้าย):** อัปโหลดสลิป/รูปไป Drive · ตรวจสลิปด้วย SlipOK · ล็อกอิน LINE/Google ·
ตัวตั้งเวลา · สำรอง/กู้คืน · ล้างเงินสมทบ/ลบสลิปซ้ำตอนยืนยัน — คำขอเหล่านี้ถูกส่งต่อไป Apps Script อัตโนมัติ

### กลไกที่มีอยู่แล้ว vs ที่ต้องเพิ่ม

| | |
|---|---|
| ✅ มีแล้ว | รายชื่อ route ที่ส่งเส้นใหม่ (`FAST_ACTIONS` ใน `api.js`) — ไม่อยู่ในรายชื่อ = ไป Apps Script · เพิ่มทีละกลุ่มตามตาราง |
| ✅ มีแล้ว | เครื่องนำร่องรายเครื่อง (`atom_fast_pilot`) — รับเฉพาะ URL ของเราเอง |
| ✅ มีแล้ว | โฮสต์ติดต่อไม่ได้/ช้าเกิน 15 วิ → **พัก 5 นาทีแล้วใช้ Apps Script เอง** โดยผู้ใช้ไม่ต้องทำอะไร |
| ✅ มีแล้ว | โฮสต์ตอบว่า "ไม่ใช่ของฉัน" → ส่งต่อ Apps Script อัตโนมัติ |
| ⬜ ต้องเพิ่ม | ทางให้เครื่องนำร่อง**เปิดเองได้ง่าย** (วันนี้ต้องตั้งค่าในเบราว์เซอร์ — ผู้ปกครองใน LINE ทำเองไม่ได้) · เสนอ: ลิงก์นำร่องที่ ผอ. ส่งให้ทีละคน |
| ⬜ ต้องเพิ่ม | ตัวนับในรายงานความเร็วแยก "เส้นใหม่/เส้นเดิม" เพื่อเทียบก่อน-หลังด้วยตัวเลขจริง |
