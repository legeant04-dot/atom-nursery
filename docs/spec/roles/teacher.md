# คู่มือการใช้งาน — คุณครู

> คุณครูประจำชั้นที่แอดมินผูก LINE ID ไว้ในระบบแล้ว · เห็นเฉพาะชั้นเรียนที่ตนดูแล

| | |
|---|---|
| เมนูที่เห็น | หน้าหลัก · นักเรียน · อุบัติเหตุ · ดำเนินการ · ตาราง · การเงิน |
| อายุการเข้าสู่ระบบ | 14 วัน นับจากครั้งล่าสุดที่เปิดแอป — ใช้งานทุกวันจะไม่มีวันหลุด |
| เวอร์ชัน | จัดทำจากระบบเวอร์ชัน 384 (2026-09-15) |

## 1 · การเข้าสู่ระบบ

**เข้าระบบด้วย LINE เท่านั้น** — เปิดแอปแล้วกด “เข้าสู่ระบบด้วย LINE” · หากเปิดจากในแอป LINE อยู่แล้ว ระบบจะเข้าให้เองโดยไม่ต้องกดอะไร

**ค้างการเข้าสู่ระบบไว้ได้** — ติ๊ก “จดจำการเข้าสู่ระบบ” ไว้ (ค่าเริ่มต้นติ๊กอยู่แล้ว) ครั้งต่อไปเปิดแอปจะเข้าหน้าหลักทันที · ติ๊กออกหากใช้เครื่องที่ยืมคนอื่นมา

**เข้าไม่ได้ทำอย่างไร** — หน้าจอจะเสนอ 3 ทางตามลำดับ: (1) เปิดในแอป LINE (2) ลองใหม่ในเบราว์เซอร์นี้ (3) เข้าสู่ระบบ LINE ด้วยอีเมล · หากผูกบัญชี Google ไว้แล้วจะมีปุ่ม Google เพิ่มให้

**ออกจากระบบทุกอุปกรณ์** — ที่หน้าข้อมูลส่วนตัว มีปุ่ม “ออกจากระบบอุปกรณ์อื่นทั้งหมด” · เครื่องที่กดยังใช้งานต่อได้ตามปกติ · ใช้เมื่อทำมือถือหายหรือเปลี่ยนเครื่อง

**ปุ่มรีเฟรช 🔄** — อยู่มุมขวาบนของหน้าหลักทุกบทบาท · กดเมื่อสงสัยว่าข้อมูลยังไม่อัปเดต · ไม่ใช่การรีโหลดหน้า จึงเร็วกว่าการปิดเปิดแอป

## 2 · หน้าจอทั้งหมด และสิ่งที่ทำได้

### 2.1 หน้าหลัก

_ลงเวลาทำงานของตนเอง และสรุปสิ่งที่ต้องทำวันนี้_

- **ลงเวลาเข้างาน / เลิกงาน** — ใช้ GPS · ระบบคำนวณการมาสายและชั่วโมง OT ให้อัตโนมัติ
- **ดูเวลาทำงานย้อนหลัง** — พร้อมเวลาที่แอดมินแก้ให้ (แสดงเป็นตัวหนาสีน้ำเงิน)
- **เตือนงานค้าง** — สมุดรายงานที่ยังไม่เขียน · เด็กที่ต้องติดตาม · การวัดการเจริญเติบโตที่ถึงกำหนด
- **ปุ่มรีเฟรช 🔄** — มุมขวาบน กดเพื่อดึงข้อมูลล่าสุด

### 2.2 นักเรียน

_รายชื่อเด็กในชั้นที่ดูแล และการทำงานรายวัน_

- **เช็คอิน/เช็คเอาต์แทนผู้ปกครอง** — ใช้เมื่อผู้ปกครองกดเองไม่ได้ · ระบบบันทึกว่าคุณครูเป็นผู้ทำ
- **เขียนสมุดรายงานประจำวัน** — อารมณ์ · สุขภาพ · นม/อาหาร · การนอน · ขับถ่าย · กิจกรรม · ทักษะ
- **แจ้งลาแทนผู้ปกครอง** — บันทึกใบลาให้เด็กที่ผู้ปกครองโทรมาแจ้ง
- **บันทึกน้ำหนัก/ส่วนสูง** — ระบบเตือนเมื่อถึงรอบที่ต้องวัด
- **ประเมินพัฒนาการ DSPM** — ตามช่วงวัยของเด็กแต่ละคน
- **ติดตามการขาดเรียน 🔴** — มีวงกลมแดงบนเมนูเมื่อมีเด็กต้องติดตาม · บันทึกว่าใครติดตาม วันไหน แนบใบรับรองแพทย์ได้

### 2.3 อุบัติเหตุ

_แบบบันทึกการบาดเจ็บรายบุคคล (แบบฟอร์มราชการ 17 ประเภท)_

- **บันทึกอุบัติเหตุ** — วันเวลา · เด็ก · เหตุการณ์ · สาเหตุ · สถานที่ · ชนิดการบาดเจ็บ · พยาน
- **แนบรูปภาพ** — ประกอบการบันทึก
- **เลือกแจ้งผู้ปกครอง** — ติ๊กเพื่อส่ง LINE ถึงผู้ปกครองทันที
- **แก้ไขรายงานที่ยังไม่ปิด** — คุณครูผู้บันทึกแก้ไขเองได้จนกว่าจะถูกอนุมัติ

### 2.4 ดำเนินการ

_เรื่องที่ต้องยื่นและรออนุมัติ_

- **ยื่นใบลา** — ลาป่วย · ลากิจ · ลาพักร้อน · ลายาว — แนบเอกสารได้
- **ดูสิทธิการลาคงเหลือ** — ของตนเอง แยกตามประเภท
- **ขอลงเวลาย้อนหลัง** — กรณีลืมลงเวลา หรือ GPS ไม่ทำงาน — ต้องผ่านการอนุมัติ 2 ขั้น
- **ดูสถานะคำขอ** — รออนุมัติหัวหน้า → รออนุมัติแอดมิน → อนุมัติแล้ว

### 2.5 ตาราง

_ตารางการทำงานและประวัติการลา_

- **ดูตารางเวรของตนเอง** — เวลาเข้า-ออกตามกลุ่มพนักงาน
- **ดูประวัติการลา** — และสถานะแต่ละใบ
- **ดูวันหยุดโรงเรียน** — และวัน Big Cleaning

### 2.6 การเงิน

_เรื่องเงินของตนเอง — ต้องใส่รหัสผ่านก่อนเปิด_

- **ดูสลิปเงินเดือน** — ย้อนหลังได้ทุกเดือน · ดาวน์โหลดเป็นไฟล์ได้
- **ดูประวัติ OT** — ทั้ง OT ปกติและ OT วันหยุด
- **เปลี่ยนรหัสผ่าน** — หรือขอรีเซ็ตจากแอดมินหากลืม

### 2.7 ข้อมูลส่วนตัว

_กดจากมุมขวาบน_

- **แก้ไขข้อมูลส่วนตัว** — ชื่อ · ชื่อเล่น · เบอร์โทร · วันเกิด · อีเมล · รูป · วุฒิการศึกษา · สาขา · วันจบ
- **ผูกบัญชี Google** — เป็นทางเข้าสำรองเมื่อ LINE มีปัญหา
- **ออกจากระบบทุกอุปกรณ์**

## 3 · กฎและเงื่อนไขที่ต้องรู้

1. **สมุดรายงานเปิดเมื่อเด็กเช็คอินแล้ว**  
   ของวันนี้เท่านั้นที่บังคับ — ย้อนหลังเขียนได้เสมอ · เป็นการยืนยันว่าเด็กมาโรงเรียนจริงก่อนบันทึก

2. **การลาต้องผ่าน 2 ขั้น**  
   คุณครูยื่น → หัวหน้าครูอนุมัติ → แอดมินอนุมัติขั้นสุดท้าย · ถ้าหัวหน้าครูหรือแอดมินยื่นเอง จะข้ามไปรอขั้นแอดมินทันที

3. **สิทธิการลาเป็นรายคน**  
   ค่าเริ่มต้น ลาป่วย 30 วัน / ลากิจ 3 วัน · ลาพักร้อนขึ้นกับอายุงาน โรงเรียนกำหนดให้รายคนได้

4. **ลงเวลาซ้ำไม่ได้**  
   ระบบจะตอบว่าลงเวลาไปแล้วพร้อมบอกเวลา — ไม่ถือเป็นข้อผิดพลาด

5. **วันหยุดไม่ต้องลงเวลา**  
   ระบบปฏิเสธการลงเวลาในวันหยุดโรงเรียน · วัน Big Cleaning เป็นวันทำงานของพนักงาน แต่ไม่ใช่วันเรียนของเด็ก

6. **เด็กที่ต้องติดตาม**  
   ขาดตั้งแต่ 2 วัน = เริ่มติดตาม · ตั้งแต่ 5 วัน = ติดตามใกล้ชิด · วงกลมแดงบนเมนูนักเรียนคือจำนวนที่ยังไม่ติดตาม

7. **รายงานอุบัติเหตุแจ้งเตือนทันที**  
   ทุกครั้งที่บันทึก ระบบส่ง LINE ถึงแอดมินและหัวหน้าเสมอ — จึงไม่ควรบันทึกเพื่อทดสอบ

## 4 · ข้อความที่ระบบอาจปฏิเสธ และวิธีแก้

| ข้อความที่เห็น | เกิดขึ้นเมื่อ | ต้องทำอย่างไร |
|---|---|---|
| ยังไม่ได้เช็คอินนักเรียนวันนี้ — กรุณาเช็คอินก่อน | จะเขียนสมุดรายงานของวันนี้ก่อนเด็กเช็คอิน | เช็คอินเด็กคนนั้นก่อน แล้วเขียนได้ทันที |
| ลงเวลาเข้างานวันนี้ไปแล้ว (…) | กดลงเวลาซ้ำ | ไม่ต้องทำอะไร ระบบบันทึกครั้งแรกไว้แล้ว |
| ยังไม่ได้ลงเวลาเข้างานวันนี้ | กดเลิกงานก่อนเข้างาน | ลงเวลาเข้างานก่อน หรือขอลงเวลาย้อนหลัง |
| วันนี้เป็นวันหยุดของโรงเรียน — ไม่ต้องลงเวลา | วันหยุดตามปฏิทิน | ไม่ต้องทำอะไร |
| วันแรกของการทำงานคือ … | ยังไม่ถึงวันเริ่มงาน | รอถึงวันที่ระบุ |
| บันทึกของวันที่ … ถูกล็อกแล้ว | เลยกำหนดแก้ไขสมุดรายงานย้อนหลัง | ขอให้แอดมินปลดล็อกให้ |
| สิ้นสุดการทำงานเมื่อ … | เลยวันทำงานวันสุดท้ายที่บันทึกไว้ | แจ้งแอดมิน หากกลับเข้าทำงานแอดมินเปิดให้ได้ทันที |

## 5 · สิ่งที่บทบาทนี้ทำไม่ได้

- ✕ ดูข้อมูลเด็กนอกชั้นที่ตนดูแล
- ✕ ดูเงินเดือนของคนอื่น
- ✕ อนุมัติใบลาของตนเอง
- ✕ แก้ไขเงินเดือน ตำแหน่ง แผนก กลุ่มพนักงาน หรือวันเริ่มงานของตนเอง
- ✕ ออกบิลหรือแก้ไขยอดเงินของผู้ปกครอง
- ✕ ปลดล็อกสมุดรายงานที่ล็อกแล้ว

## 6 · หมายเหตุการจัดทำ

สร้างจากการอ่านโค้ดและชุดทดสอบของระบบจริง ไม่ใช่จากความจำ · ก่อนใช้เป็นข้อกำหนดของระบบใหม่ ขอให้ผู้ใช้งานจริงของบทบาทนี้อ่านและยืนยัน — หากพบข้อใดไม่ตรง ให้ถือว่าคู่มือผิด เพราะระบบใหม่จะถูกสร้างตามคู่มือนี้
