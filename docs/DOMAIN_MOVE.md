## 📋 ลำดับ 9 ขั้น

### ✅ ขั้น 1 — ปล่อย "รุ่นส่งมอบ" ก่อน *(ทำแล้ว v465)*

**ทำก่อนทุกอย่าง และต้องรออย่างน้อย 1-2 สัปดาห์ให้ผู้ปกครองเปิดแอปจนได้รับรุ่นนี้**

รุ่นนี้ใส่ของ 2 อย่างลงในเครื่องผู้ปกครอง:

| | ทำอะไร |
|---|---|
| **ตัวกัน "หน้าขาว"** | SW เดิมถ้าเจอ 301 จากเซิร์ฟเวอร์ **เบราว์เซอร์จะปฏิเสธและขึ้นหน้าขาว** · รุ่นนี้แปลงเป็น redirect ที่ถูกต้อง · **ทำงานตลอดเวลา ไม่ต้องรอเปิดสวิตช์** |
| **สวิตช์ `MIGRATE_TO`** | ยังปิดอยู่ · รอวันที่เราเปิด |

> 🔴 **นี่คือขั้นที่ข้ามไม่ได้และต้องมาก่อนสุด**
> เครื่องที่ยังไม่ได้รับรุ่นนี้ จะเจอหน้าขาวในวันที่เราชี้โดเมน — และ**เราไล่แก้ทีละเครื่องไม่ได้**

### ⬜ ขั้น 2 — จดโดเมน
`atomnursery.co.th` (หรือ `.ac.th`) · **~800 ฿/ปี** · ใช้เวลาตรวจเอกสารสูงสุด ~2 สัปดาห์
เอกสาร: **หนังสือรับรอง (ออกไม่เกิน 6 เดือน)** + สำเนาบัตรกรรมการ

### ⬜ ขั้น 3 — ตั้ง DNS
ชี้ไปที่ GitHub Pages — **ยืนยัน IP กับเอกสาร GitHub ณ วันที่ทำจริง** *(เปลี่ยนได้)*
```
A     @      185.199.108.153
A     @      185.199.109.153
A     @      185.199.110.153
A     @      185.199.111.153
CNAME www    legeant04-dot.github.io
```

### ⬜ ขั้น 4 — ผูกโดเมนกับ GitHub Pages
Settings → Pages → Custom domain → รอ DNS check ผ่าน → **เปิด "Enforce HTTPS"**
*(ใบรับรอง Let's Encrypt ฟรี ออกให้อัตโนมัติ อาจใช้เวลาถึง 24 ชม.)*

### 🔴 ขั้น 5 — **แก้ปลายทางที่ LINE** *(ลืมข้อนี้ = ทั้งโรงเรียนล็อกอินไม่ได้)*
LINE Developers → LIFF → **Endpoint URL** → โดเมนใหม่
LINE Login channel → **Callback URL** → เพิ่มโดเมนใหม่

> **อย่าลบของเดิมทิ้งทันที** — ใส่ทั้งสองอันไว้ก่อน จนกว่าจะแน่ใจว่าไม่มีใครค้างอยู่ที่เก่า

### 🔴 ขั้น 6 — แก้ที่ Google
Google Cloud Console → OAuth client → เพิ่ม **Authorized JavaScript origins** และ **redirect URIs** ของโดเมนใหม่

### ⬜ ขั้น 7 — ทดสอบจริงบนมือถือ **ก่อน** เปิดสวิตช์

| ต้องผ่านทุกข้อ |
|---|
| เปิด `https://atomnursery.co.th` แล้วแอปขึ้น |
| **ล็อกอิน LINE ได้** ทั้งในแอป LINE และในเบราว์เซอร์ |
| ล็อกอิน Google ได้ |
| ติดตั้งเป็นแอป (Add to Home Screen) ได้ |
| เช็คอิน/เช็คเอาต์ได้ *(GPS ทำงาน — ต้องเป็น HTTPS)* |
| ที่อยู่เดิมยังเปิดได้ตามปกติ *(ยังไม่เปิดสวิตช์)* |

### 🔴 ขั้น 8 — เปิดสวิตช์ `MIGRATE_TO`
แก้ **2 ไฟล์ให้ตรงกัน** แล้วปล่อยรุ่นใหม่:
```js
webapp/sw.js    const MIGRATE_TO = 'https://atomnursery.co.th';
webapp/app.js   const MIGRATE_TO = 'https://atomnursery.co.th';
```
`tools/test_domain_move.js` จะฟ้องถ้าสองไฟล์ไม่ตรงกัน

**ตั้งแต่วินาทีนี้** ทุกคนที่เปิดที่อยู่เดิม จะถูกส่งไปโดเมนใหม่อัตโนมัติ พร้อม path เดิม

## ❓ คำถามที่ควรถามก่อนเริ่ม

**"ทำไมไม่ย้ายโฮสต์ไปด้วยเลยทีเดียว?"**

เพราะถ้าย้ายสองอย่างพร้อมกันแล้วพัง **เราจะไม่รู้ว่าพังเพราะอะไร** — และนี่คือระบบที่โรงเรียนใช้จริงทุกเช้า
*(และ ผอ. เลือก "ย้ายโดเมนก่อน แยกคนละรอบ" ไว้แล้วเมื่อ 22/10)*

**"ผู้ปกครองต้องติดตั้งแอปใหม่ไหม?"**

**ไม่ต้อง** — นั่นคือเหตุผลทั้งหมดของขั้น 1 และ 8
ของเดิมบนเครื่องเขาจะพาเขาไปที่ใหม่เอง · **และนี่คือเหตุผลที่การมีโดเมนของตัวเองคุ้ม**: ครั้งหน้าที่เราย้ายโฮสต์ ผู้ปกครองจะไม่รู้สึกอะไรเลยแม้แต่น้อย
