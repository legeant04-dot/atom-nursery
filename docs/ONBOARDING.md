## 🔴 สิ่งที่ต้องเข้าใจก่อนเริ่ม

**เวลาส่วนใหญ่ของชั่วโมงนี้ ไม่ใช่การเขียนโค้ด** — `setupAll()` สร้างชีตครบ 46 ตาราง
และใส่ค่าตั้งต้นครบ 80 คีย์ได้ในไม่กี่วินาที · ของจริงที่กินเวลาคือ **บัญชีกับบุคคลที่สาม**
ซึ่ง**ต้องมีคนนั่งหน้าเบราว์เซอร์ทำ** และสคริปต์แทนไม่ได้

| ขั้นตอน | ใครทำได้ | เวลาโดยประมาณ |
|---|---|---|
| สร้างชีต + ใส่ค่าตั้งต้น | **โค้ด** | < 1 นาที |
| LINE OA + Messaging API + LIFF | **คน** (เว็บ LINE Developers) | ~20 นาที |

| พิกัด GPS · ชั้นเรียน · แผนราคา · กลุ่มเวลา | **คน** (ในแอป) | ~15 นาที |
| นำเข้ารายชื่อเด็ก/ผู้ปกครอง/พนักงาน | **โค้ด + คน** | แล้วแต่จำนวน |

## 🔴 ข้อควรระวังที่สำคัญที่สุด — เจอ 15/10/2569

**ห้ามเริ่มโรงเรียนใหม่ด้วยการ "คัดลอก Google Sheet ของโรงเรียนเดิม"**

การคัดลอกเร็วกว่ามาก จึงเป็นวิธีที่คนจะทำจริง — และมันจะพาสิ่งเหล่านี้ติดไปด้วย

| ค่าที่ติดไป | ผลที่เกิดขึ้น |
|---|---|
| `SlipOK_Url` · `SlipOK_ApiKey` | 🔴 **สลิปของผู้ปกครองโรงเรียนใหม่ จะถูกตรวจผ่านบัญชี SlipOK ของโรงเรียนเดิม · ใช้โควตาของโรงเรียนเดิม · และ API key ของโรงเรียนเดิมจะไปอยู่ในชีตของบริษัทอื่น** |
| `GPS_Lat` · `GPS_Lng` | 🔴 ไม่มีใครที่โรงเรียนใหม่ลงเวลาได้เลย · และคนที่ยืนอยู่หน้าโรงเรียนเดิมลงเวลาได้ |
| `Plans` · `PrepayTiers` | 🔴 **ราคาของโรงเรียนเดิม** ไปออกบิลให้ผู้ปกครองโรงเรียนใหม่ |
| `SchoolName` · `LineOAId` · `Links_*` | ชื่อและ LINE ของโรงเรียนเดิม แสดงให้ผู้ปกครองโรงเรียนใหม่เห็น |

**ไม่มีอะไร error เลย ทั้งสองโรงเรียนจะดูปกติจนกว่าโควตา SlipOK จะหมด**

> ค่าตั้งต้นใน `src/Config.gs` **ถูกล้างให้ว่างแล้ว** (15/10/2569) ดังนั้นโรงเรียนที่สร้างด้วย
> `setupAll()` จะเริ่มจาก "ไม่มีอะไรเลย" แทนที่จะเริ่มจาก "บัญชีของคนอื่น"
> `ONBOARD_ATOM_VALUES_` ใน `src/Onboarding.gs` คือ**ตาข่ายรองรับกรณีคัดลอกชีต** —
> ปุ่มตรวจความพร้อมจะฟ้องทันทีถ้ายังเป็นค่าของ Atom

## ✅ ขั้นตอน

### 0 · ก่อนเริ่ม — เก็บข้อมูลจากโรงเรียน

ขอจากโรงเรียนให้ครบก่อน จะได้ไม่ต้องหยุดกลางทาง

- ชื่อโรงเรียน (ไทย/อังกฤษ) · สโลแกน
- **ที่อยู่ + พิกัด GPS ของอาคาร** (เปิด Google Maps คลิกขวาที่ตัวอาคาร → คัดลอกพิกัด)
- ชื่อชั้นเรียน/แผนก ทั้งหมด
- **แผนราคา** และส่วนลดชำระล่วงหน้า
- เวลาเข้า–ออกงาน (มีกี่กลุ่ม)
- บัญชีธนาคาร + PromptPay + รูป QR
- เบี้ยขยัน · เรท OT · เรทจำนวนเด็ก · อัตราสมทบ
- บริษัทประกัน + เลขกรมธรรม์

### 1 · สร้างสเปรดชีตและสคริปต์ *(โค้ด · < 1 นาที)*

1. สร้าง Google Sheet 2 ไฟล์ใน**บัญชี Google ของโรงเรียนเอง** — ไฟล์หลัก + ไฟล์ฝ่ายบุคคล
2. สร้างโปรเจกต์ Apps Script ผูกกับไฟล์หลัก · `clasp push` โค้ดชุดเดียวกัน
3. รัน `setupAll()` จาก editor → ได้ 46 ตาราง พร้อมหัวคอลัมน์ และ 80 คีย์ค่าตั้งต้น
4. Deploy เป็น Web App → ได้ URL

> **ทำไมต้องเป็นบัญชีของโรงเรียน:** `docs/pdpa/01_DPA.md` ข้อ 1.3 บอกว่าข้อมูลเป็นของโรงเรียน ·
> ถ้าไฟล์อยู่ในบัญชีเรา ประโยคนั้นจะไม่เป็นจริงตั้งแต่วันแรก

### 2 · LINE *(คน · ~20 นาที)*

1. สร้าง **LINE Official Account** ของโรงเรียน → ได้ `@xxxxx`
2. LINE Developers → Messaging API channel → เอา **Channel access token** + **Channel secret**
3. สร้าง **LIFF app** ชี้ไปที่ URL ของ Web App → ได้ **LIFF ID**
4. *(ถ้าต้องการให้เข้าผ่านเบราว์เซอร์ได้ด้วย)* สร้าง **LINE Login channel** แยกอีกตัว
   → เอา Channel ID + Secret · และ**ใส่ URL ของแอปใน Callback URL list** *(ขั้นนี้ลืมบ่อยที่สุด)*
5. เอาแอดมินของโรงเรียนไปเพิ่มเพื่อนกับ OA แล้วหา **LINE userId** ของแอดมิน

### 3 · SlipOK *(คน · ~10 นาที)*

1. สมัคร SlipOK ในนามโรงเรียน · ผูกบัญชีธนาคารของโรงเรียน
2. **เลือกแพ็กเกจและชำระเงิน** — แพ็กเกจที่หมดอายุ = ตรวจสลิปไม่ได้เลย
3. หน้า **สาขา** → คัดลอก **เลขสาขา (Branch ID)** และ **API Key ของสาขานั้น**

> 🔴 **"เลขอ้างอิงการแจ้งเตือน" (`slipok-xxxx-…`) ไม่ใช่ API key** — เป็นคนละค่ากัน
> ใส่ผิดจะได้ code 1002 `Authorization Header ไม่ถูกต้อง` *(เกิดขึ้นจริงกับ Atom เมื่อ 14/10/2569)*

### 4 · *(ถ้าต้องการ)* Sign in with Google *(คน · ~10 นาที)*

Google Cloud Console → OAuth client (ID-token sign-in · scope แค่ `email` + `profile`)
→ ใส่ `GoogleClientId` · **ไม่มี client secret ให้เก็บ** · เว้นว่าง = ปิดฟีเจอร์ ปุ่มจะไม่ขึ้น

### 5 · ตั้งค่าในแอป *(คน · ~15 นาที)*

ตั้งค่า › ตั้งค่าโรงเรียน · ตั้งค่าการเงิน · ตั้งค่าวันลา · กลุ่มพนักงาน · ย้าย/จัดชั้นเรียน

### 6 · 🔴 ตรวจความพร้อม *(โค้ดตอบ · 10 วินาที)*

**จัดการ › ⚙️ ตั้งค่า & เครื่องมือ › 🩺 เครื่องมือตรวจสอบ › 🏫 ตรวจความพร้อมของโรงเรียน**

ระบบจะไล่ตรวจทุกคีย์แล้วบอกว่า

| | |
|---|---|
| 🔴 **ติดขัด** | ยังเปิดใช้งานไม่ได้ — ขาดค่า หรือยังเป็นค่าของโรงเรียนอื่น |
| ⚠️ **ต้องมีก่อนให้ผู้ปกครองเข้า** | ขาดได้ชั่วคราว แต่จะพังแบบเห็นชัด |
| 📋 **ยืนยันว่าเป็นของโรงเรียนนี้** | มีค่าตั้งต้นที่ใช้ได้ แต่เป็น**การตัดสินใจเชิงธุรกิจ** (ราคา · เรท OT · เบี้ยขยัน) |

และนับสิ่งที่การตั้งค่าสร้างแทนไม่ได้: **ชั้นเรียน · แผนราคา · กลุ่มพนักงาน · พนักงาน · นักเรียน**

> **ทำไมเป็น "ปุ่มตรวจ" ไม่ใช่ "checklist ให้ติ๊ก":** checklist คือรายการที่คนดูแลเอง
> และโปรเจกต์นี้โดนรายการแบบนั้นเล่นงานมาแล้ว 4 ครั้ง · คนติ๊กว่า "ตั้ง GPS แล้ว ✓"
> คือการ**ยืนยันสิ่งที่ไม่มีใครตรวจ** · อันนี้ถาม**ระบบ**ว่ามีแถวไหม ว่างไหม ยังเป็นค่าของ Atom ไหม

### 7 · นำเข้ารายชื่อ และเปิดใช้งาน

1. นำเข้าพนักงาน → ตั้งแอดมินของโรงเรียน
2. นำเข้านักเรียน + ผู้ปกครอง
3. **ตั้งค่า › อัปเดตตาราง** — สรุปรายวันและตัวเฝ้า SlipOK จะยังไม่ทำงานจนกว่าจะกดปุ่มนี้
4. 🔔 ตั้งค่าการแจ้งเตือน — **ค่าตั้งต้นคือปิดทุกหัวข้อ โดยเจตนา**
   โรงเรียนใหม่ที่ไม่ส่งอะไรเลยคือโรงเรียนที่สงบ · ที่ส่งทุกอย่างวันแรกคือ ticket
5. 📦 **กดสำรองข้อมูลทั้งโรงเรียน 1 ครั้ง** แล้วส่งไฟล์ให้โรงเรียนเก็บ —
   เป็นการพิสูจน์ข้อ 9.1 ของ DPA ตั้งแต่วันแรก ไม่ใช่ตอนเลิกสัญญา
