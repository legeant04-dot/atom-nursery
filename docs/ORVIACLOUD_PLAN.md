## 2. สี่หน้าที่ของโดเมน — แต่ละหน้าที่ต้องมีอะไร

### 2.1 🏠 เว็บหลัก (`orviacloud.com`)

ยึดวิธีขายใน `docs/OPERATING_COSTS.md` §7 — **ขายผลลัพธ์ ไม่ขายซอฟต์แวร์**

| หน้า | เนื้อหา |
|---|---|
| หน้าแรก | "ครูได้เวลาคืนวันละครึ่งชั่วโมง · ผู้ปกครองเห็นลูกถึงโรงเรียนทันที · เงินไม่ตกหล่น" + ภาพจากโรงเรียนสาธิต |
| ราคา | 3 แพ็กเกจ ฿199 / ฿299 / ฿399 ต่อเด็กต่อเดือน · ขั้นต่ำ 20 คน · เกิน 30 คนขอใบเสนอราคา (`PRICING_AND_TENANCY.md`) |
| เรื่องจริงจากโรงเรียน | Atom Nursery เป็นโรงเรียนอ้างอิง — 🔑 **ต้องขออนุญาต ผอ. ก่อนเอ่ยชื่อ** (`OPERATING_COSTS.md` §7.2) |
| ขอทดลองใช้ | ฟอร์มสั้น: ชื่อโรงเรียน · จำนวนเด็ก · ผู้ติดต่อ · LINE/โทร · **กล่องยินยอม PDPA** |

## 6. สรุปหนึ่งย่อหน้า

`orviacloud.com` จดแล้วแต่ยังไม่อยู่ใน process ไหน · เอกสารนี้วางไว้เป็น **4 ส่วนใต้โดเมนเดียว** —
เว็บหลัก/ขาย (`orviacloud.com`) · ดูแลลูกค้า (`help.` · `status.` · LINE OA ของแพลตฟอร์ม) · หลังบ้าน (`console.`) ·
และแอปของโรงเรียนอื่น (`app.` · `api.`) · **ตอนนี้ทำแค่ระยะ 0** (DNS · อีเมล · หน้าเดียว · จอง `@orvia`) ซึ่งไม่ต้องเขียนโค้ด
และไม่มีค่าใช้จ่าย · ระยะ 1 เริ่มหลังวันตัดระบบ Atom · ระยะ 2 ผูกกับ Phase 4 เมื่อมีโรงเรียนทดลองรายแรก ·
ระยะ 3 เมื่อมีโรงเรียนจ่ายเงินที่ไม่มีโดเมนเอง · สิ่งที่ต้องได้จาก ผอ. ก่อนเริ่มระยะ 0 คือ **รหัสเข้าที่จดโดเมน**
และ **ตัดสินเรื่องอีเมล**
