## 🔙 ถอย — เลือกตามว่าเปิดรับการเขียน (ขั้น 7) แล้วหรือยัง

**ก่อนขั้น 7** (ยังแช่แข็ง): ลบ Script Property `DB_BACKEND` → deploy Apps Script รุ่นก่อนคืน D → push เว็บรุ่นก่อน → `unfreezeWrites()`
ทุกคนกลับไปใช้ชีตที่แช่แข็งไว้ **ไม่มีข้อมูลหาย** · ⚠️ `SESSION_SECRET` ใหม่ยังอยู่ → ทุกคนล็อกอินใหม่ 1 ครั้ง (คืนค่าเดิมได้ถ้า ผอ. เก็บไว้ — **ถามก่อนคืน D ว่าจะเก็บค่าเดิมไว้ไหม**)

**หลังขั้น 7** (มีการเขียนลง Postgres แล้ว) — ตาม `src/Rollback.gs`:
1. `freezeWrites()`
2. `rollbackToSheets()` — สร้างสำเนาจากไฟล์ `MOVE-D-` แล้วเติมทุกอย่างที่เขียนหลังย้าย · รันซ้ำจนเสร็จ (หยุดเองก่อนครบ 6 นาที)
3. อ่านรายงาน — **ไม่ตรงแม้ช่องเดียว = ไม่สลับ** อยู่บน Postgres ต่อ แก้ปัญหาที่ต้นเหตุแทน
4. `rollbackActivate()` (ชี้ไปสำเนา + ปิด `DB_BACKEND`) → เว็บรุ่นก่อน → `unfreezeWrites()`
5. เปลี่ยนใจกลับ Postgres: `rollbackUndoActivate()`

**เซิร์ฟเวอร์ใหม่อย่างเดียวมีปัญหา** (ข้อมูลไม่ผิด): ล้าง `FAST_URL` ในเว็บแล้วปล่อยรุ่นใหม่ → ทุกคำขอไป Apps Script (บน Postgres เดียวกัน · ช้า 5–8 วิ/หน้า แต่ถูกต้อง) · ข้อมูลไม่หาย · ~10 นาที
แอปเองก็ถอยไป Apps Script อัตโนมัติ 5 นาทีต่อเครื่องเมื่อโฮสต์ไม่ตอบใน 15 วิ
