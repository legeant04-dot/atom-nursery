## 📹 เขียนเผื่อไว้ · กล้องวงจรปิด (CCTV) — ยังไม่ได้ทำ

ตามที่ ผอ. ระบุไว้ 2026-10-21 สำหรับคำขอของโรงเรียนอื่นในอนาคต

### 🔴 ข้อสรุปที่ต้องยึดก่อนเขียนโค้ดบรรทัดแรก

> **วิดีโอของเด็ก คือข้อมูลส่วนบุคคลที่อ่อนไหวที่สุดที่ระบบนี้จะเคยแตะ**
> หนักกว่าเบอร์โทร หนักกว่าเลขบัตร และ **เป็นข้อมูลของเด็กคนอื่นพร้อมกันเสมอ**
> กล้องในห้องเรียนไม่เคยเห็นลูกของคนเดียว

**ผลที่ตามมา 4 ข้อ:**

1. **ภาพต้องไม่ผ่านเซิร์ฟเวอร์เรา** — เราออก *ตั๋วชั่วคราว* ให้ไปดูจากผู้ให้บริการกล้องโดยตรง
   เราไม่เก็บ ไม่ส่งต่อ ไม่สำรองวิดีโอ · **ของที่เราไม่เคยถือ คือของที่เราทำหลุดไม่ได้**
2. **PDPA ต้องมีข้อตกลงแยกต่างหาก** — ไม่ใช่ข้อเดียวในสัญญาเดิม ต้องมีความยินยอมของผู้ปกครอง**ทุกคนในห้องนั้น** ไม่ใช่แค่คนที่ขอดู
3. **ทุกครั้งที่เปิดดูต้องถูกบันทึก** — ใคร · กล้องไหน · เมื่อไหร่ · กี่นาที
   **ผู้ปกครองคนอื่นต้องขอดูบันทึกนี้ได้** ว่าใครดูห้องที่ลูกเขาอยู่บ้าง
4. **ครูต้องรู้ว่ากล้องกำลังถูกดูอยู่** — การถูกดูโดยไม่รู้ตัวคือสภาพการทำงานคนละแบบ

### โครงสร้างที่วางไว้

```
ผู้ปกครอง → แอปเรา → ขอ "ตั๋ว" → เซิร์ฟเวอร์เราตรวจ 4 ชั้น
                                   ① เป็นผู้ปกครองของเด็กที่ยังเรียนอยู่จริง (parentOwnsStudent_)
                                   ② กล้องตัวนี้ผูกกับ "ชั้นเรียนของลูกเขา" เท่านั้น
                                   ③ อยู่ในเวลาที่โรงเรียนเปิดให้ดู
                                   ④ โควต้าวันนี้ยังเหลือ
                                 → ออก signed URL อายุสั้น (≤ 60 วินาที)
                                 → ผู้ปกครองต่อตรงไปที่ผู้ให้บริการกล้อง
```

**คีย์ตั้งค่าที่จะต้องมี** *(ยังไม่สร้าง — เขียนไว้ให้ครบตอนทำจริง)*

| คีย์ | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `CctvEnabled` | โรงเรียนนี้เปิดใช้ไหม | `false` |
| `CctvProvider` | ยี่ห้อ/ผู้ให้บริการ | `''` |
| `CctvDailyQuotaMin` | **โควต้าต่อวันของผู้ปกครอง 1 คน** | `30` |
| `CctvQuotaChoices` | ตัวเลือกที่แอดมินเลือกได้ | `15,30,45,60` |
| `CctvOpenFrom` / `CctvOpenTo` | ช่วงเวลาที่เปิดให้ดู | `08:00` / `17:00` |
| `CctvSessionMaxMin` | ครั้งเดียวดูได้ไม่เกินกี่นาที | `10` |
| `CctvRetentionDays` | เก็บ log การเข้าดูกี่วัน | `90` |

**ชีตใหม่ 2 ตาราง:** `CCTV_CAMERAS` (กล้อง ↔ ชั้นเรียน) · `CCTV_VIEW_LOG` (ใคร ดูอะไร เมื่อไหร่ กี่วินาที)

### ⏱️ เรื่องโควต้าเวลา — และข้อผิดพลาดที่ต้องไม่ทำ

ผอ. เสนอ **15 / 30 / 45 / 60 นาทีต่อวัน** · เห็นด้วย และขอเพิ่ม 4 ข้อ:

| 🔴 กฎ | เพราะอะไร |
|---|---|
| **นับเวลาที่ฝั่งเซิร์ฟเวอร์ ไม่ใช่ฝั่งแอป** | ตัวจับเวลาในแอปคือตัวจับเวลาที่ปิดแท็บแล้วรีเซ็ต · ให้ตั๋วหมดอายุทุก ≤60 วิ แล้ว**หักโควต้าตอนออกตั๋ว** |
| **โควต้าเป็นของ "ครอบครัว" ไม่ใช่ของ "บัญชี"** | ไม่งั้นพ่อ 30 + แม่ 30 + ยาย 30 = ห้องเดียวถูกดู 90 นาที |
| **บอกเวลาที่เหลือก่อนกด ไม่ใช่ตัดกลางคัน** | *"วันนี้เหลือ 12 นาที"* — ตัดกลางคันโดยไม่เตือน ผู้ปกครองจะอ่านว่าแอปพัง |
| **ปิดประตูด้วยกฎเดียวกับที่เหลือทั้งระบบ** | เด็กออกจากโรงเรียนแล้ว = ดูกล้องไม่ได้ทันที **ไม่ต้องรอ 30 วันผ่อนผัน** — ผ่อนผันมีไว้ให้เคลียร์บิลและโหลดเอกสาร ไม่ใช่ให้ดูห้องเรียนที่ลูกไม่ได้อยู่แล้ว |

> **และข้อที่สำคัญที่สุด:** ต่อ API กล้องได้ ≠ ควรต่อ
> ถ้าโรงเรียนไหนขอ ให้ถาม ผอ. และทนายก่อนเสมอ — นี่เป็นเรื่องเดียวในระบบที่ *"ทำได้"* กับ *"ควรทำ"* ห่างกันมากที่สุด
