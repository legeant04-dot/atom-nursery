### ③ 🔴 แล้วการแก้ ② ก็สร้างบั๊กเงินตัวใหม่ทันที

Postgres driver ส่ง `numeric` กลับมาเป็น**ข้อความ** โดยเจตนา · `'18000.00' + '1200.50'` = `'18000.001200.50'`

**ประชด**: เปลี่ยนเป็น numeric *เพื่อ*ปกป้องตัวเงิน และการเป็น numeric คือสิ่งที่ทำให้มันกลายเป็นข้อความ

**และข้อสอบเดิมปิดบั๊กนี้ไว้เอง**: `Number(pgM.staff[0].BaseSalary) === 16000` — ครอบ `Number()` ใน assertion เอง
จึงทดสอบ "ค่า" และมองไม่เห็น "ชนิด" · ผ่านสบายบน `'16000.00'`

> **ข้อสอบที่แปลงค่าก่อนเทียบ คือข้อสอบที่ทดสอบการแปลงของตัวเอง**

`test_pg_engine` 33 → **41 ข้อ** · กวาด**ทุกช่องเงินของทุกแถว** ไม่ใช่สุ่มตัวเดียว (ไม่งั้น 12 จาก 13 หลุดอีก) · **ถอดการแก้ออก → ตก 7 ข้อ**

### ④ `--reset` ที่ปฏิเสธตัวเองเมื่อมีข้อมูล

`node tools/pg_connect.js --reset` นับแถวทุกตารางก่อน · **เจอแถวใดๆ = ปฏิเสธ** (ทดสอบแล้ว ใส่ 1 แถว → ปฏิเสธและบอกชื่อตาราง)

ไล่ตรวจครบทั้ง 4 handler ที่เรียก `resolveParent_` — ไม่มีจุดอื่นที่ขาด

**ใบลาที่ Admin แจ้ง = ใบลาของโรงเรียน** (`FiledBy`) ตัดสินจาก **session** ไม่ใช่จาก payload
เพราะตอนดูมุมมอง ระบบส่ง `parentId` ของครอบครัวนั้นจริง ๆ ไม่มีอะไรอื่นแยกออกได้

**🔴 Error pop-up ค้าง เฉพาะตอนบันทึก** — `api.js` ติดป้ายชื่อ action และ "เขียนข้อมูลหรือไม่" ลงบน error
→ `err()` เลือกระหว่าง toast กับ dialog ที่ต้องกดปิด · แสดงรหัสข้อผิดพลาดด้วย เพราะ "ลองใหม่อีกครั้ง"
ไม่มีอะไรให้โรงเรียนรายงานกลับมา · **อ่านไม่ขึ้น dialog** — p50 7.3s, fail ~1/40 ส่วนใหญ่เป็นป้ายตัวเลข

### Phase 4 — บันทึกนักเรียน (v423)

ปฏิทิน วัน/เดือน/ปี บนหัวจอชั้นเรียน (`<input type="date">` จำกัดไม่เกินวันนี้)

**🔴 ความเสี่ยงไม่ได้อยู่ที่ตัวปฏิทิน** — `classList` ตอบเป็น "วันนี้" เสมอไม่ว่าจะขอบันทึกของวันไหน
ดังนั้นทุกแถวยังถือเวลาเช็คอินของวันนี้ การ์ด "วันนี้ไม่มาเรียนตามที่ตกลงไว้" และป้ายเตือน DSPM ของวันนี้
— ทุกอย่างเป็นความจริงของคนละวัน และปุ่มเช็คอินจะเสนอให้กดย้อนหลังซึ่งเซิร์ฟเวอร์ปฏิเสธ
→ วันย้อนหลังเหลือแค่ **👁️ ดูบันทึก** กับ **⋯** เปลี่ยนสีพื้นหลัง และบอกเป็นคำว่าอ่านได้อย่างเดียว

**ไม่จำวันที่ข้ามการโหลด** — เปิดแอปตอนเช้าแล้วเจอวันอังคารที่แล้วโดยกดอะไรไม่ได้ แย่กว่าการกดเพิ่มอีกครั้ง

กล่องวันเกิดย้ายลงใต้รายชื่อเด็ก เพราะมันมี ◀ ▶ ของตัวเอง และลูกศรสองชุดซ้อนกันอ่านว่าเป็นอันเดียวกัน

### ตรวจสอบทั้งระบบ (v425)

- **🔴 เจอ handler ตาย 1 จุดใน 505** — `onclick="…toast(…)"` ในกล่อง Callback URL
  `onclick` ทำงานใน **global scope** แต่ `toast` อยู่ใน IIFE → ReferenceError ทุกครั้งที่แตะ
  (คัดลอกสำเร็จเพราะเป็นครึ่งซ้ายของ `&&` แล้วค่อย throw — ผู้ใช้ไม่เคยได้รับคำยืนยัน)
  แก้เป็น `window.COPY_` ซึ่งรองรับกรณี `navigator.clipboard` ไม่มี (nonsecure context) ด้วย
  → **`tools/test_inline_handlers.js`** ตรวจทั้งไฟล์ทุกครั้ง และมีการปลูก handler ปลอมเพื่อพิสูจน์ว่าตัวตรวจยังจับได้
- deployment จริงแข็งแรง: ping 20 ครั้ง **ok 20/20** p50 3.3s p95 8.5s
- เคยเจอ 404 / `ok:false` 3 ครั้งติดก่อนหน้านั้น แล้วหายเอง — **เป็นอาการของ Apps Script ไม่ใช่จากการ deploy**
  ตรงกับ `BAD_RESPONSE HTTP 404` ที่มีใน perf report อยู่แล้ว
- หน้าแรกคุณครู **13 คำสั่ง 1 คำขอ** และบันทึกตั้งค่า **9 คำสั่ง 1 คำขอ** — ยืนยันในเบราว์เซอร์จริง
- `Engine.gs` ตรงกับ `engine.js` · dist build ตรงกับ v425 · shadow routes ผ่าน 36/36
